# Pembaruan taxonomy X — 18 November 2026

Versi: `x-policy-2026-11-18-v2`. Taxonomy adalah pemetaan kebijakan untuk triase teks, bukan salinan lengkap menu Report X. Metadata `source_topics` memuat topik yang dipetakan dari sumber; label Indonesia adalah terjemahan, dan tidak semua topik merupakan rule klasifikasi tersendiri.

Halaman resmi X ditinjau menggunakan akses riset web karena permintaan langsung dari VPS mengembalikan HTTP 403. Empat belas halaman kebijakan untuk 14 kategori ditinjau, ditambah aturan umum X dan kebijakan merek dagang. Hasilnya dikurasi, bukan sinkronisasi otomatis yang terus berjalan; script di VPS tetap melaporkan 403 dan tidak menimpa taxonomy.

Perubahan penting:
- Dua rule baru `civic.suppression` dan `civic.intimidation` merujuk pada [Civic Integrity](https://help.x.com/en/rules-and-policies/election-integrity-policy); keduanya membutuhkan review/verifikasi konteks.
- Rule `ip.trademark` merujuk pada [Trademark policy](https://help.x.com/en/rules-and-policies/x-trademark-policy), bukan halaman hak cipta.
- Referensi alur laporan dicantumkan hanya jika didokumentasikan secara eksplisit: [konten intim tanpa persetujuan](https://help.x.com/en/rules-and-policies/intimate-media) untuk report post dan [entitas kekerasan/kebencian](https://help.x.com/en/rules-and-policies/violent-entities) untuk report account. Pilihan berikutnya dapat berbeda sesuai konteks.
- ID rule lama tetap tersedia. Review yang dibuat dengan `x-policy-2026-11-11-v1` tetap dapat diputuskan memakai rule versi lama. Knowledge versi lama tetap tersimpan namun tidak digunakan otomatis oleh taxonomy versi baru.
